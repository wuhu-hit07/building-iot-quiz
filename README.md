# 建筑工程物联网 · 专项刷题

面向广联达 BIM 毕业设计创新大赛资格海选赛的网页版专项题库。题目围绕《建筑工程物联网》（王建玉、耿立明主编，高等教育出版社，ISBN 978-7-04-061607-1）的四个模块组织。

## 题库概况

| 模块 | 题量 |
| --- | ---: |
| 模块一 建筑工程物联网概述 | 15 |
| 模块二 物联网感知层传感技术及应用 | 32 |
| 模块三 物联网的网络层及其应用 | 23 |
| 模块四 物联网应用规划设计 | 30 |

题型比例：

- 单选题 50 道
- 多选题 30 道

- 综合应用题 10 道

- 基础 40 道
- 提高 40 道
- 难题 20 道

## 证据级别

每题均标注依据级别，避免把推断内容冒充教材原文：

- **教材样章已核实**：来自高等教育出版社官方样章第 13—21 页，可直接核对 WSN、七类无线技术、视频监控电源监测和塔机监测等内容。
- **教材目录推导**：依据出版社官方目录中的模块、项目和任务名称命题，正文细节尚未逐页核对。
- **原理拓展**：教材任务相关的电子技术、视觉识别或工程原理拓展，正文未核验。

当前没有获得官方海选赛真题、完整电子教材或出版社配套题库。本页面题目为原创命题，不标注为“官方真题”。

## 本地预览

在 `iot-quiz` 目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:4173/
```

直接双击 `index.html` 也可以打开，但用本地服务器更接近实际部署环境。

## 部署

这是纯静态站点，不需要构建。把整个 `iot-quiz` 目录上传到 GitHub Pages、Netlify、Vercel 或学校服务器即可。

GitHub Pages 的一种做法：

1. 新建仓库，把 `iot-quiz` 内的文件放到仓库根目录。
2. 在仓库 Settings → Pages 中选择部署分支和根目录。
3. 等待 Pages 构建完成，访问生成的网址。

`.nojekyll` 已保留，避免 GitHub Pages 忽略静态资源。

## 修改题目

题目集中在 `questions.js` 的 `RAW_QUESTIONS` 数组中。每题包含：

```js
{
  id: "M2-001",
  module: "M2",
  project: "项目2.1 数据采集类传感技术",
  task: "任务2.1.1 烟雾传感器及应用",
  evidence: "toc",              // sample | toc | supplement
  difficulty: "基础",           // 基础 | 提高 | 难题
  type: "single",               // single | multiple | judgment | scenario
  stem: "题干",
  choices: [{ key: "A", text: "选项" }],
  answer: "B",                  // 多选使用 ["A", "C"]
  explanation: "解析",
  knowledge: "知识点",
  source: "依据说明"
}
```

新增题目后刷新页面即可，统计数量和模块分布会自动计算。

页面加载时会对非判断题做确定性选项轮换，避免正确答案长期集中在 A。`answer` 仍按 `RAW_QUESTIONS` 中选项的原始 key 填写，轮换后会自动映射；判断题保持 A 正确、B 错误。
